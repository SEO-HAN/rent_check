# 서버 Claude Code 작업 지시문 (복사해서 붙여 넣기용)

> 사용법: 서버에서 터미널 2개 — ① 앱 터미널 `streamlit run app.py` ② 작업 터미널 `cd ~/work/rent_check && claude` → 아래 지시를 **하나씩** 붙여 넣기.
> 커밋 후 `git push` 하면 Streamlit Cloud 공개 주소에 자동 반영됩니다. 화면 수정 후에는 앱 터미널에서 Ctrl+C → `streamlit run app.py`.
> 각 단계가 끝날 때마다 **① 실행 확인 → ② SPEC.md 기대값과 대조 → ③ `git commit` → ④ AI_LOG.md 한 줄**을 반복합니다.
> AI가 틀리거나 마음에 안 드는 결과를 주면 **바로 거부하거나 고치게 하고**, 그 내용을 AI_LOG에 적으세요(제출 양식 2-4, 3-3에 씁니다).

## 0단계 — 시작 확인 (지시 1)

```
CLAUDE.md, SPEC.md, data/README.md 를 읽고 이 프로젝트의 구조와 규칙을 5줄로 요약해 줘. 코드는 아직 고치지 마.
```
- 확인: 요약이 CLAUDE.md 내용과 맞는지 직접 읽고 비교하세요.

## US-1 — 홈 화면 마무리 (지시 2)

```
SPEC.md 의 US-1 완료 조건대로 app.py 를 확인하고, 빠진 것이 있으면 app.py 만 고쳐 줘. 이미 충족하면 고치지 말고 "충족"이라고만 알려 줘.
```
- 확인: `streamlit run app.py` → 홈에 "120건", "진단 시작"이 보이는지 확인합니다.
- 커밋: `git add . && git commit -m "US-1: 홈 화면"`

## US-3 — 계산 로직 + 테스트 (지시 3) ※ 입력 화면보다 먼저 만듭니다

```
SPEC.md 의 "2. 계산 규칙" 대로 core.py 에 validate_input, monthly_cost, find_similar, judge 4개 함수를 추가해 줘.
그리고 test_core.py 에 "검증용 기대값" 5개와 예외 입력(면적 0, 월세 0) 테스트를 추가하고 python -m pytest -q 결과를 알려 줘.
core.py 와 test_core.py 외의 파일은 고치지 마.
```
- 확인: `python -m pytest -q`가 모두 통과하는지 확인합니다. 기대값(47.5 / 38.5 / +23.4% / 비쌈 등)을 **직접 SPEC.md 표와 대조**하세요.
- AI가 기대값을 바꾸려 하거나 테스트를 고쳐서 통과시키려 하면 **거부**하세요. 이것이 AI_LOG의 좋은 "거부 사례"가 됩니다.
- 커밋: `git commit -am "US-3: 계산 로직과 테스트"`

## US-2 — 입력 화면 (지시 4)

```
SPEC.md 의 US-2 완료 조건대로 pages/1_매물입력.py 를 만들어 줘. 검증은 core.validate_input 을 쓰고, 통과하면 st.session_state["room"] 에 저장해 줘.
지역과 방 형태 선택지는 데이터에서 읽어 와. pages/1_매물입력.py 만 고쳐 줘.
```
- 확인: 기본값으로 진단 → 저장 안내가 뜨는지, 면적 0 → st.warning이 뜨는지 확인합니다.
- 커밋: `git commit -am "US-2: 매물 입력 화면"`

## US-4 — 결과 화면 (지시 5)

```
SPEC.md 의 US-4 완료 조건대로 pages/2_진단결과.py 를 만들어 줘. st.session_state["room"] 을 읽어 core.find_similar, core.judge 로 계산하고
st.metric 2개, 판정 문구, 근거 3줄, 비교 매물 표를 보여 줘. 입력이 없으면 st.warning 을 띄워 줘. pages/2_진단결과.py 만 고쳐 줘.
```
- 확인: 기본값(와우리/원룸/20/500/40/5) → **47.5 / 38.5 / +23.4% / 비쌈**이 나오는지, 결과 화면을 바로 열면 경고가 뜨는지 확인합니다.
- 커밋: `git commit -am "US-4: 진단 결과 화면"`

## ✋ AI 없이 직접 바꾸기 (제출 양식 2-5) — Claude Code를 끄고 직접

Claude Code를 **종료한 상태에서** 편집기(nano/vim/VS Code)로 직접 하나 고칩니다. 예시는 다음과 같습니다.
- `pages/2_진단결과.py`: 결과 맨 위에 입력값 요약 한 줄 추가 (`st.caption(f"{room['area']} {room['room_type']} {room['size_m2']}㎡ · 보증금 {room['deposit']} / 월세 {room['monthly_rent']}")`)
- 또는 `core.py`의 판정 기준을 10%에서 15%로 바꾸고 테스트 기대값도 직접 수정
- 확인: `streamlit run app.py` 또는 `python -m pytest -q`
- 커밋: `git commit -am "직접 수정: 결과 화면에 입력 요약 추가"` → 해시와 시각을 메모해 두세요 (`git log -1 --format="%h %ad"`)
