## A. GitHub · 서버 · Streamlit Cloud 연결

흐름: **모든 작업은 학교 서버 한 곳에서** (Claude Code 개발 · 앱 실행 · 로그 복사). GitHub는 Streamlit Cloud 공개 주소용입니다.

1. **GitHub**에서 New repository로 새 저장소 `rent_check`를 만듭니다. Public, README·.gitignore·license는 **모두 체크하지 않습니다**(빈 저장소).
   - 웹에서 "Upload files"로 올리지 마세요. US-0 커밋과 연결되지 않아 커밋 해시가 어긋납니다.
2. 클라우드 세션의 Claude에게 저장소 주소를 알려 주면 US-0 커밋을 push해 줍니다.
3. **학교 서버**에서 실행합니다. 처음 한 번만 하면 됩니다.
   ```bash
   cd ~/work && git clone https://github.com/<내아이디>/rent_check.git
   cd rent_check
   git config user.name "한은영" && git config user.email "<GitHub 이메일>"
   pip install -r requirements.txt     # 이미 설치돼 있으면 생략
   python -m pytest -q                 # 1 passed
   streamlit run app.py                # 앱 주소 확인 → 프로젝트파일.txt ①에 기록
   ```
   - 앱 터미널은 켜 둔 채 **터미널을 하나 더 열어** `cd ~/work/rent_check && claude`로 개발합니다. 화면을 고친 뒤에는 앱 터미널에서 `Ctrl+C` → `streamlit run app.py`로 재시작합니다.
   - 서버에서 `git push`할 때 비밀번호 대신 **GitHub Personal Access Token**을 입력합니다(GitHub → Settings → Developer settings → Tokens). push가 막혀도 서버 앱과 제출에는 문제없고, 공개 주소만 늦게 반영됩니다.
4. **Streamlit Community Cloud**(share.streamlit.io)에서 GitHub로 로그인한 뒤 Create app을 누릅니다. Repository `<내아이디>/rent_check`, Branch `main`, Main file `app.py`로 지정하고 Deploy합니다. 이후 `git push`를 하면 자동으로 다시 배포됩니다.
5. 서버 앱 터미널은 **평가 기간 내내 켜 둡니다.** 3일 자동 로그아웃에 걸리면 다시 로그인해 `streamlit run app.py`를 실행하세요.
