# data/ — 데이터 설명

## rooms.csv (가상 데이터)

수원대 주변 4개 지역의 자취방 매물 **120건**입니다(지역 4 × 방 형태 3 × 10건).
**실제 매물이 아니라 수업용으로 만든 가상 데이터**입니다. 실제 시세와 다를 수 있습니다.
지역 기본 시세, 방 형태, 면적, 건축 연수, 도보 거리, 풀옵션 여부, 보증금에 따라 월세를 정하고 잡음을 더해 만들었습니다(난수 seed 고정).

| 열 이름 | 뜻 | 형식 · 값 |
|---|---|---|
| `room_id` | 매물 번호 | 문자, R001 ~ R120 |
| `area` | 지역 | `와우리`, `봉담읍내`, `병점역`, `수원역` |
| `room_type` | 방 형태 | `원룸`, `1.5룸`, `투룸` |
| `size_m2` | 전용 면적 | 실수, ㎡ (원룸 16~26, 1.5룸 24~33, 투룸 33~50) |
| `floor` | 층 | 정수, 1 ~ 5 |
| `building_age` | 건축 연수 | 정수, 년 (1 ~ 30) |
| `walk_min` | 학교·역까지 도보 시간 | 정수, 분 (2 ~ 20) |
| `deposit` | 보증금 | 정수, 만원 (300 / 500 / 1000) |
| `monthly_rent` | 월세 | 정수, 만원 |
| `maintenance_fee` | 관리비 | 정수, 만원 (3 / 5 / 7 / 10) |
| `full_option` | 풀옵션 여부 | `Y` / `N` |

- 위 11개 열 외의 열 이름은 쓰지 않습니다. 계산으로 만든 열(예: `monthly_cost`)은 CSV에 저장하지 않고 코드 안에서만 만듭니다.
- 비어 있는 칸(결측치)은 없습니다.
