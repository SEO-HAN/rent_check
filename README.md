# 🏠 방값체크 — 수원대 주변 자취방 월세 적정가 진단

> 자취방을 구하는 대학생을 위해, 매물 조건을 넣으면 비슷한 매물 시세와 비교해 적정 월세와 판정 근거를 알려 주는 서비스

머신러닝프로젝트(RISE) 1단계 개인 프로젝트 · 한은영 (25016088)

## 화면 구성

| 화면 | 파일 | 하는 일 |
|---|---|---|
| 홈 | `app.py` | 서비스 소개, 데이터 규모, "진단 시작" |
| 매물 입력 | `pages/1_매물입력.py` | 지역·방 형태·면적·보증금·월세·관리비 입력과 검증 |
| 진단 결과 | `pages/2_진단결과.py` | 환산 월 비용과 적정가 비교, 판정(비쌈/적정/저렴), 근거 3줄, 비교 매물 |

## 판정 방법 (요약)

1. **환산 월 비용** = 월세 + 관리비 + 보증금 × 6% ÷ 12 (단위: 만원)
2. **비슷한 매물** = 같은 지역 · 같은 방 형태 · 면적 ±5㎡ (3건 미만이면 면적 조건 제외)
3. **적정가** = 비슷한 매물 환산 월 비용의 중앙값 → 차이율 +10% 이상 **비쌈**, −10% 이하 **저렴**, 그 사이 **적정**

자세한 규칙과 검증용 기대값은 [SPEC.md](SPEC.md)에 있습니다.
